坐标轴与方向设置

默认右手系

输出轴对应哪个原始传感器轴？加速度、角速度、磁场和姿态会统一使用此映射。

姿态解算需右手系：每个原始轴使用一次；例如同时翻转 X、Y 可以。仅反转一个传感器轴会被拒绝。

场景方向会同时作用于模型姿态、位置和轨迹。单独翻转一个场景轴是显示镜像；欧拉角仍描述镜像前的参考右手系。

应用仅改变选中设备的当前运行配置，重置姿态参考和位移估算，需重新初始化；记录或回放期间不可更改。坐标配置和原始采样保存到动作会话；重启后默认取身体配置文件。
