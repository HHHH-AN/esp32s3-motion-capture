- 节点协议 ID：`imu_305A6077C398`，从芯片 MAC 确定性生成；同一块板保持相同 ID，不同板可区分。
- 固件版本：`imu-wifi-node-20261025`。
- 构建环境：`esp32-s3-devkitm-1`，项目源码使用 `-Wall -Wextra -Werror` 编译通过；PlatformIO 构建与上传成功，写入块哈希校验通过。
- RAM 静态占用 45128 / 327680 字节（13.8%），Flash 程序占用 726533 / 1310720 字节（55.4%）。未测功耗，不给出数值结论。

- 当时未修改确认过的传感器引脚、坐标设置或私有网络凭据。修改前源码备份位于原工作机的 `hardware_tests/before_wifi_validation/`，该备份未随伙伴包提供。

## 本次代码变更

1. 默认使用芯片 MAC 派生唯一节点 ID；若以后确需手工 ID，可设置 `IMU_USE_MAC_NODE_ID=0`。数据格式仍为 16 列 IMU2。
2. 明确自建热点地址 `192.168.4.1`、可见 2.4 GHz 信道 1、最大 4 个客户端；TCP 仍为 9000。
3. STA 入网模式关闭 Wi-Fi 省电，以降低连续传输的省电影响；当前实测的是 AP 模式。
4. 增加网络模式、信道、关联客户端数与固件 ID 日志，启用 Arduino loop task watchdog。
5. USB 原始帧输出只在 USB 串口处于连接状态时进行，Wi-Fi 采样不等待串口打开。

第一轮在无线已关联但 DHCP IPv4 路由未就绪时失败，报 Windows 10051；加入有限的路由等待后通过。这是本轮明确定位并处理的连接问题。不能把“Windows 已关联”直接等同于“TCP 已连通”。

最近一轮 179 次网页接口轮询记录中，观测到传感器角速度模长最高约 235.37°/s，Roll 范围约 -114.92° 至 -2.68°，证明该段数据并非始终静止的常量。但没有量角器/转台真值，因此不声明已验证旋转角度精度。该轮起止时的姿态重建次数均为 2，没有在该轮增加；这是服务运行以来的累计值，不能解释为该轮发生了 2 次重启。不能将无线平均频率约 98 Hz 当成严格均匀 100 Hz 或多节点同步证据。

## 实时查看旋转

新增程序 `run_wifi_monitor.py` 只使用标准库和项目已有纯 Python 姿态函数，可配置 1—3 个真实 TCP 节点。没有配置的槽位显示“未配置”，断开的节点显示“离线”，不生成模拟动作。

原测试时启动的本机服务使用以下页面地址；本次整理不会启动硬件接收服务：

```text
http://127.0.0.1:8010/
```

测试结束已恢复原 Wi-Fi，页面此时显示 A 离线是预期行为。要观察实时转动，先在 Windows 连接已保存的 `ESP32-IMU`，再查看该页面，程序会自动重连；热点提示无 Internet 不影响本机页面。完成本地观察后可重新连接原 Wi-Fi 继续在线对话。

以后重启服务时，在项目目录运行：

```powershell
python -B -X utf8 host/run_wifi_monitor.py --node A=192.168.4.1:9000
```

或：

```powershell
.\tools\start_wifi_monitor.ps1
```

同一板子目前只接受一个 TCP 客户端。不要同时运行原单节点开发台连接、三节点实验采集、直接接收脚本和本实时监控去连接同一板子。

页面“参考姿态归零”仅设置当前显示参考，不做陀螺零偏、传感器安装或人体关节标定。当前显示的是传感器自身旋转，不是已经重建的人体关节角；不做位移积分。

## 三节点的下一步

电脑和三个节点需要位于能够互访的同一局域网。可以继续验证共同手机热点/路由器；也可验证节点 A 作热点、其余两个节点作为 STA 入网的拓扑，A/B 双节点后续已验证，第三节点尚未实测。不要把三块板都配置为同名独立热点后当作同一网络。

确认另外两块板的实际 IP 后，实时监控程序支持：

```powershell
python -B -X utf8 host/run_wifi_monitor.py --node A=192.168.4.1:9000 --node B=实际IP:9000 --node C=实际IP:9000
```

上述 B/C 地址为占位说明，需要真实地址。每个节点独立解析、融合、参考姿态和统计；当前未实现三节点采样同步、肢段安装标定或实时关节角计算。下一阶段先证明三路真实节点同时稳定更新，再进入 `../experiments.md` 中的同刚体检查与人体实验。
