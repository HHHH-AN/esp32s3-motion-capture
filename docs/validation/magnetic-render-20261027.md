## 三维磁校准实现与本轮拒绝结果

增加标准库实现的对称椭球拟合、硬铁偏置和软铁校正矩阵，参考 [NXP AN4246](https://www.nxp.com/docs/en/application-note/AN4246.pdf) 的椭球到球模型。矩阵限定为合理正定矩阵，检查场强、残差、三个轴两侧范围、八象限计数及方向协方差。拟合失败不生成候选，不自动修改设备参数。

校正应用在原始传感器坐标系、轴映射之前。原始磁场保存在 `raw`；校正后的映射磁场与校准标识进入记录及设备快照。按物理ID保存到 `host/config/magnetometer_v1.json`，应用时撤销姿态安装参考并清除旧磁场质量基线；陀螺零偏保留。记录/回放期间禁止应用。

拟合工具只读取已保存会话：

```powershell
host/.venv/Scripts/python.exe tools/fit_magnetometer.py host/recordings/实际会话 --device imu_305A6077C398 --output 实际候选.json
```

合格候选经现有 `/ws/body` 控制通道的 `set_magnetic_calibration` 命令显式应用；包含目标 `device_id` 和候选 `calibration` 对象。不合格采集不应手工绕过门槛或复制合成参数。

最后一段共2994个样本，磁场模长峰值约36401.7mG，693个样本（约23.1%）超过5000mG，并非仅一两个瞬时尖峰。六面段与绕轴段联合拟合也不成立。不能据此认定具体干扰物或硬件故障，也不能继续将失败归因于用户没有按三轴转动。

电脑扬声器/电机/大电流路径、手机磁吸附件、耳机与充电仓磁铁、铁质桌面或支架均需排查。先固定位置、移开干扰物，查看磁场读数是否恢复稳定，再安排新的三维采集。参考 [NXP 磁力计布局及干扰来源](https://www.nxp.com/company/about-nxp/smarter-world-blog/BL-MAGNETOMETER-PLACEMENT-WHERE-WHY)。
