# 三节点旋转实验

当前已保留四套预设：`rigid_check`、`upper_limb`、`lower_limb`、`bilateral`。它们复用同一协议和姿态模块，默认使用合成数据；只有显式选择 `--live` 才连接三个端点。历史实板证据覆盖 A/B，第三节点、人体关节角和同步精度尚未验证。

## 方案与测量含义

| 预设 | A / B / C 位置 | 输出与边界 |
| --- | --- | --- |
| `rigid_check` | 同一非金属刚板上的三个节点 | 比较相对旋转偏离；先排查安装、坐标、磁场和时间错位 |
| `upper_limb` | 胸廓 / 同侧上臂 / 同侧前臂 | 肘部、上臂相对胸廓夹角及重复动作统计；先做慢速肘屈伸 |
| `lower_limb` | 骨盆 / 同侧大腿 / 同侧小腿 | 膝部及大腿相对骨盆夹角；先做受控慢速膝屈伸 |
| `bilateral` | 胸廓 / 左上臂 / 右上臂 | 左右抬举角度、幅度差和节奏；前平举与侧平举分开采集 |

夹角是静态姿势标定后肢段长轴的无符号三维夹角。只有在约束平面的简单动作中才近似解释为屈伸角；当前没有完整解剖关节坐标系、功能轴辨识或精确三自由度关节角。固定根部骨架的端点由姿态和骨长推算，不是空间位置实测。

## 离线演示

从仓库根运行：

```powershell
python -B -X utf8 host/run_motion_presets.py --preset rigid_check --demo
python -B -X utf8 host/run_motion_presets.py --preset upper_limb --demo
python -B -X utf8 host/run_motion_presets.py --preset lower_limb --demo
python -B -X utf8 host/run_motion_presets.py --preset bilateral --demo
```

或运行 `tools/start_preset.ps1 -Preset upper_limb`。默认输出在 `host/preset_runs/` 的新会话中，终端打印 HTML 报告路径。报告可离线查看角度曲线、示意骨架、回放和统计，无需 CDN。合成数据包含理想旋转、重力和磁场，不包含真实人体、噪声、强动态加速度或磁干扰。

## 接入真实三个节点

三块板和电脑必须能在同一局域网互访。可以使用共同路由器/手机热点，也可继续验证 A 为 AP、B/C 为 STA 的拓扑；不能把三个同名独立热点当作同一网络。当前固件已有 B 客户端环境，第三节点还需独立环境与地址。每块板只能由一个 TCP 接收程序连接，采集前关闭其他监控。

将 `host/presets/endpoints.example.json` 复制为 `host/presets/endpoints.local.json`，填写 A/B/C 的不同真实地址与端口。槽位的身体含义由所选预设决定；传感器轴映射与人体安装标定是两件事，沿用 `host/coordinate_settings.json` 的映射，确有硬件差异时在本地端点配置中逐节点明确设置。

```powershell
python -B -X utf8 host/run_motion_presets.py --preset rigid_check --live --endpoints host/presets/endpoints.local.json --duration 30
```

三个连接建立后，按提示保持中立姿势至少 4 秒；最初 3 秒用于陀螺零偏与静态姿势标定，动作统计排除该段。初始出现明显运动时拒绝分析并保留原始记录。先做同刚体旋转，再进入某一人体预设；初期每次 20—30 秒。允许范围是 8—120 秒，不代表长时同步或航向稳定性已验证。

## 记录与复算

| 文件 | 内容 |
| --- | --- |
| `session.json` | 预设、来源、端点和各节点坐标快照 |
| `raw.csv` | 槽位、电脑接收时刻及原始协议行 |
| `aligned.csv` | 公共显示网格、有效标志、夹角、角速度和四元数 |
| `summary.json` | 校准、缺帧、角度范围、次数、周期及限制 |
| `report.html` | 独立交互报告 |
| `error.json` | 失败原因；出现失败记录不能视为成功实验 |

复算时保留同目录的 `session.json`：

```powershell
python -B -X utf8 host/run_motion_presets.py --preset upper_limb --replay "host/preset_runs/你的会话目录/raw.csv"
```

回放保留原来的方案、坐标和来源标签；合成演示回放后仍是演示。程序不覆盖已有输出目录。

## 算法边界与验收顺序

各节点独立完成 IMU2 解析、微秒时钟回绕展开、静置零偏、姿态融合和固定安装偏置。相邻肢段通过相对四元数求长轴夹角，不直接相减欧拉角。中立标定假定各肢段参考轴平行，不能自动判断佩戴姿势是否正确或修复不同节点受到的不同磁干扰。

时间映射使用静置段最小的“电脑接收时间 − 设备时间”估计固定偏移，然后按 50 Hz 网格插值；未知单向网络延迟与时钟频偏仍存在。30 ms 匹配容差不是同步精度声明，25 Hz 数据插值为 50 Hz 也不会增加采样信息。超过允许插值间隔时留空，较大缺口、重启或时间异常会停止本轮分析并保留原始数据。

动作计数默认要求回低位、越高位、再回低位才完成一次，阈值可在预设 JSON 调整；周期重复性不等于角度精度或动作质量。默认骨长为示意，应按佩戴者测量；未经传感器测量的肢段不补造为实测全身动作。

建议顺序：三路身份明确且持续接收 → 同刚体检查 → 带刻度铰链的已知角度重复验证 → 简单慢速人体动作三组重复 → 再考虑快速动作和扩大节点数。同刚体最大相对偏离约 5° 只能作为待实测确认的工程门槛，不能作为精度保证。
