## 此前单板实测同步：2026-10-25

以下为用户转交的旁支对话实测结果，本次仅同步记录，未重新执行测试：Python 3.12.14 可用；VS Code 启动 `host/run_dashboard.py` 后，8000 开发台正常运行；默认环境 `esp32-s3-devkitm-1` 编译、烧录成功，当前电脑与成功识别的单块板已跑通 USB 和 Wi-Fi 两条实时姿态链路。存在姿态漂移，已交队友处理，本轮未修复或验证精度。

最初那块板在用户和队友电脑均无法识别，原因未定，不能认定为驱动问题。更换的板烧录前为 COM7（VID:PID `303A:1001`，SER `98:C3:77:60:9B:14`）；COM 号须在后续操作前重新确认。其他板正在使用，本轮未进行多板测试。

本轮通过 `PLATFORMIO_OFFLINE=1` 临时绕过依赖安装失败，通过 `subst M:` 和英文构建路径绕过中文路径链接失败；这不表示全局环境已修复。映射和终端环境变量当前是否保留未知，不自动清理。私有 `wifi_config.h` 在测试时不存在，使用 `firmware/include/wifi_config.example.h` 的默认热点配置（SSID 为 `ESP32-IMU`）；连接密码以该文件为准，旧交接密码不适用于本轮固件。

详细命令、边界和后续交接见代码工作区内部记录 `.codex/handoffs/20261025-single-board-hardware-test.md`。本轮没有长时间稳定性、重连、精度、A/B 并发或三节点实板验收，不能视为整个系统验收完成。
